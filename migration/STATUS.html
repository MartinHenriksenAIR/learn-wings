Operational quirks

  • Smoke tests hit the regionalized host, not the SWA origin (see the checkpoint above). POST-only endpoints such as organizations and platform-settings answer a GET with 404 — use POST and expect 401 unauthenticated.
  • There is no working telemetry (#452). The function app's App Insights component points at a deleted Log Analytics workspace, fleet-wide. Nothing you log reaches a queryable place — never send anyone to App Insights to diagnose. Diagnose production read-only through the database and the endpoints themselves.
  • Post-deploy the function host can park in Error (worker-restart exhaustion during zipdeploy file churn). Wait for the ~3 min file sync to settle, then az functionapp restart.
  • The Key Vault ai-education-migration uses RBAC, not access policies. az keyvault set-policy fails outright. Grant with az role assignment create --role "Key Vault Secrets User" --assignee <principalId> --scope $(az keyvault show --name ai-education-migration --query id -o tsv); allow ~30s to propagate. A missing role makes KV references render as the literal @Microsoft.KeyVault(...) string at runtime — the CLI omits values, so verify in the portal (Function App → Environment variables → green ✓).
  • The orphan sweep is the only unattended deleter in the system. functions/orphan-sweep fires daily at 03:00 UTC and deletes blobs older than 24h that no DB row references. Treat unexplained missing media as a sweep question first. Kill switch: ORPHAN_SWEEP_DISABLED=1 on the function app. There is an undo — the storage account has 7-day blob soft-delete with allowPermanentDelete=false, verified to catch a SAS-token DELETE. Recover with az storage blob undelete; list casualties with az storage blob list --include d --auth-mode key --query "[?deleted]". Note #451: the per-bucket tripwire has deadlocked every run since day one.
  • gh 403 "Must have admin rights to Repository" means the wrong active account. This repo is emkataumre — fix with gh auth switch --user emkataumre.

Accepted trade-offs

  • Enroll does a check-then-insert TOCTOU on course availability — harmless; UNIQUE(org_id,user_id,course_id) backstops it.
  • Platform admins can write course_reviews in orgs they aren't members of — a consequence of the suite-wide admin-bypass convention.
  • grade-quiz silently records no quiz_attempts row for a platform admin with no membership.
